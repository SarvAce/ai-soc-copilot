# Deviations and clarifications

Where `docs/POC_SPEC.md` (proposal v1.0.2) is silent or ambiguous, this file records
what the implementation does, why, and which section it concerns. It feeds proposal v1.1.

No ID, threshold, window, rule row, check or expected outcome has been changed.
